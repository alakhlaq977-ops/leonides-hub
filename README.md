# LeOniDeS Hub

أريد منك إنشاء موقع ويب احترافي وكامل لصانع المحتوى المصري **مروان ريحان – LeOniDeS**، بالاعتماد على الهوية البصرية للقناة ومحتواها، وليس مجرد Landing Page بسيطة.

**مهم جدًا:**
الموقع يجب أن يكون باللغة العربية بشكل أساسي، مع دعم كامل للـ RTL، ويكون Responsive 100% على الكمبيوتر والموبايل والتابلت.

## 1. هوية الموقع

اسم الموقع:
**Marwan Rehan – LeOniDeS**

استخدم شعار القناة والصور الرسمية الخاصة بمروان ريحان إذا كانت متاحة بشكل قانوني وعلني من مصادره الرسمية.

أريد أن يكون تصميم الموقع مستوحى من هوية القناة ومحتوى مروان:

* Gaming
* Movies
* Entertainment
* Action
* Comedy
* Streaming

اجعل التصميم حديثًا جدًا، Gaming/Creator Style، ويشبه مواقع كبار صناع المحتوى، وليس شكل موقع شركات تقليدي.

## 2. الخلفية الرئيسية

أريد استخدام صورة القناة/الـ Channel Art الرسمية كخلفية أساسية للموقع عندما تكون الصورة متاحة.

الخلفية تكون:

* Full screen
* Cover
* Fixed أو Parallax بشكل احترافي
* عليها طبقة Overlay مناسبة حتى يكون الكلام واضحًا
* لا تجعل الخلفية تؤثر على سرعة الموقع
* استخدم Lazy Loading وضغط الصور عند الحاجة

إذا لم تتمكن من الحصول على صورة القناة الرسمية تلقائيًا، اجعل هناك مكان واضح في إعدادات الموقع أستطيع من خلاله رفع صورة الـ Channel Banner يدويًا.

* تاريخ النشر
* عدد المشاهدات إذا كان متاحًا
* زر مشاهدة الفيديو

عند الضغط على الفيديو:

* افتح الفيديو على YouTube أو اعرضه داخل الموقع بطريقة احترافية باستخدام YouTube Embed.

اجعل الفيديوهات قابلة للتحديث بسهولة.

إذا كان YouTube API متاحًا، استخدمه لجلب أحدث الفيديوهات تلقائيًا.

إذا لم يكن API متاحًا، اعمل نظامًا يسمح بإضافة الفيديوهات يدويًا من لوحة الإدارة.
